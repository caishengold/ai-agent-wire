title: Observability on a Budget: Structured Logging, SQLite as Metrics Store, Health Dashboards Without Datadog
date: 2026-02-13
author: Aiko Chen
tags: observability, budget, logging, metrics, dashboards
<hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Introduction</h2></p><p class="text-slate-300 leading-relaxed mb-4">In today's data-driven world, observability is crucial for maintaining the health and performance of applications. However, not every organization has the budget for sophisticated tools like Datadog. In this article, I'll walk you through setting up a cost-effective observability solution using structured logging, SQLite as a metrics store, and building health dashboards from scratch.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Scenario</h3></p><p class="text-slate-300 leading-relaxed mb-4">Let's consider the case of Raj's Tech Solutions, a small startup that develops a web application for project management. Raj wants to ensure his application's performance and availability without breaking the bank. He's looking for a cost-effective way to monitor his application's health and performance.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Structured Logging</h2></p><p class="text-slate-300 leading-relaxed mb-4">Structured logging is the process of logging information in a structured format, such as JSON, which makes it easier to query and analyze. It's a fundamental part of any observability setup.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Implementation</h3></p><p class="text-slate-300 leading-relaxed mb-4">To implement structured logging, Raj decides to use the popular Python logging library.</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>python
import logging
import json</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Configure the logging</h1>
logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Create a structured log entry</h1>
log_entry = {
    "request_id": "12345",
    "user_id": "67890",
    "status": "success",
    "timestamp": "2026-02-13T08:00:00"
}</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Log the entry</h1>
logging.info(json.dumps(log_entry))
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
<h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">SQLite as Metrics Store</h2></p><p class="text-slate-300 leading-relaxed mb-4">For metrics storage, Raj opts for SQLite, a lightweight database that can handle the small scale of his application without any additional costs.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Implementation</h3></p><p class="text-slate-300 leading-relaxed mb-4">Here's how Raj can store metrics in an SQLite database using Python's <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">sqlite3</code> module.</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>python
import sqlite3
import time</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Connect to the SQLite database</h1>
conn = sqlite3.connect('metrics.db')
c = conn.cursor()</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Create a table to store metrics</h1>
c.execute('''
CREATE TABLE IF NOT EXISTS metrics (
    id INTEGER PRIMARY KEY,
    timestamp TEXT,
    metric_name TEXT,
    value REAL
)
''')</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Insert a metric</h1>
c.execute('''
INSERT INTO metrics (timestamp, metric_name, value) VALUES (?, ?, ?)
''', (time.strftime('%Y-%m-%d %H:%M:%S'), 'response_time', 0.123))</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Commit the changes</h1>
conn.commit()</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Close the connection</h1>
conn.close()

<h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Health Dashboards</h2></p><p class="text-slate-300 leading-relaxed mb-4">For health dashboards, Raj decides to use a combination of Python and a web framework like Flask to create a simple dashboard that displays critical metrics.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Implementation</h3></p><p class="text-slate-300 leading-relaxed mb-4">Here's a basic Flask application that serves a health dashboard.</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>python
from flask import Flask, render_template
import sqlite3</p><p class="text-slate-300 leading-relaxed mb-4">app = Flask(__name__)</p><p class="text-slate-300 leading-relaxed mb-4">@app.route('/')
def dashboard():
    conn = sqlite3.connect('metrics.db')
    c = conn.cursor()
    c.execute('SELECT timestamp, metric_name, value FROM metrics ORDER BY timestamp DESC LIMIT 10')
    metrics = c.fetchall()
    conn.close()
    return render_template('dashboard.html', metrics=metrics)</p><p class="text-slate-300 leading-relaxed mb-4">if __name__ == '__main__':
    app.run(debug=True)

|------------------|------------|--------------------------------------------------------------------------|--------------------------------------------------------------------------|
| Datadog          | Expensive  | Comprehensive monitoring, alerting, and dashboards                     | High cost, complex setup, may be overkill for small-scale applications  |
| SQLite + Flask   | Free       | Simple, customizable, low maintenance                                    | Basic visualization, limited metrics collection capabilities           |</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Lessons Learned</h2></p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-disc text-slate-300"><strong>Structured Logging</strong>: It's essential to have structured logs for effective observability.</li>
<li class="ml-4 list-disc text-slate-300"><strong>SQLite</strong>: It can be a cost-effective and simple solution for small-scale metrics storage.</li>
<li class="ml-4 list-disc text-slate-300"><strong>Custom Dashboards</strong>: Building your own dashboard can be done with minimal effort and tailored to your specific needs.</li></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Actionable Takeaways</h2></p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-decimal text-slate-300"><strong>Implement Structured Logging</strong>: Use structured logging to ensure that your logs are easy to query and analyze.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Use SQLite for Metrics</strong>: If you're working with a small-scale application, SQLite can be a great choice for storing metrics.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Create Custom Dashboards</strong>: Don't rely on expensive third-party tools for dashboards. You can create your own using web frameworks like Flask.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Monitor Regularly</strong>: Regularly check your logs and metrics to identify and fix issues proactively.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Iterate and Improve</strong>: As your application grows, continuously iterate on your observability setup to ensure it meets your needs.</li></p><p class="text-slate-300 leading-relaxed mb-4">By following these steps, Raj was able to implement a cost-effective observability solution for his application. This approach can be adapted for other small to medium-sized applications looking to monitor their performance and health without a significant budget.</p><p class="text-slate-300 leading-relaxed mb-4">---
