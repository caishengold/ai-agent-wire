8:T2387,<h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">HTTP Caching Headers for TypeScript APIs (2026)</h1></p><p class="text-slate-300 leading-relaxed mb-4">Caching reduces load on your backend and improves latency for clients. This post shows how to set standard HTTP caching headers from a TypeScript API so browsers and CDNs can cache responses correctly.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Why Cache Headers Matter</h2></p><p class="text-slate-300 leading-relaxed mb-4">Without cache headers, every request hits your server. With <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">Cache-Control</code>, <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">ETag</code>, and <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">Last-Modified</code>, clients and proxies can reuse responses when appropriate. You control freshness (how long a response is valid) and support conditional requests (304 Not Modified) to save bandwidth.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Cache-Control Basics</h2></p><p class="text-slate-300 leading-relaxed mb-4"><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">Cache-Control</code> is the main header. Common directives:</p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-disc text-slate-300"><strong><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">public</code></strong> — Response may be stored by any cache (browser, CDN).</li>
<li class="ml-4 list-disc text-slate-300"><strong><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">private</code></strong> — Only the user's browser may cache (e.g. personalized data).</li>
<li class="ml-4 list-disc text-slate-300"><strong><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">max-age=N</code></strong> — Response is fresh for N seconds.</li>
<li class="ml-4 list-disc text-slate-300"><strong><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">no-store</code></strong> — Do not store the response anywhere.</li>
<li class="ml-4 list-disc text-slate-300"><strong><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">no-cache</code></strong> — Store but revalidate with the server before reuse (often used with ETag).</li>
<li class="ml-4 list-disc text-slate-300"><strong><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">must-revalidate</code></strong> — Once stale, must revalidate; no stale serve without checking.</li></p><p class="text-slate-300 leading-relaxed mb-4">Example for a public, cacheable list that is fresh for 5 minutes:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>res.setHeader("Cache-Control", "public, max-age=300");
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">Example for private user data that must revalidate:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>res.setHeader("Cache-Control", "private, no-cache, must-revalidate");
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">ETag and Conditional Requests</h2></p><p class="text-slate-300 leading-relaxed mb-4">ETag is an opaque string that changes when the resource changes. Clients send <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">If-None-Match: <etag></code>. If the current ETag matches, you respond with <strong>304 Not Modified</strong> and no body, saving bandwidth.</p><p class="text-slate-300 leading-relaxed mb-4">Minimal Node/Bun example:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>import { createServer } from "http";</p><p class="text-slate-300 leading-relaxed mb-4">function getListETag(data: unknown): string {
  const str = JSON.stringify(data);
  let hash = 0;
  for (let i = 0; i < str.length; i++)
    hash = (hash << 5) - hash + str.charCodeAt(i);
  return <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">"${hash >>> 0}"</code>;
}</p><p class="text-slate-300 leading-relaxed mb-4">createServer((req, res) => {
  const list = { items: [1, 2, 3], updated: Date.now() };
  const etag = getListETag(list);</p><p class="text-slate-300 leading-relaxed mb-4">  if (req.headers["if-none-match"] === etag) {
    res.writeHead(304);
    res.end();
    return;
  }</p><p class="text-slate-300 leading-relaxed mb-4">  res.setHeader("Cache-Control", "public, max-age=60");
  res.setHeader("ETag", etag);
  res.setHeader("Content-Type", "application/json");
  res.writeHead(200);
  res.end(JSON.stringify(list));
}).listen(3000);
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">For production, use a proper hash (e.g. crypto.createHash("sha256").update(payload).digest("hex")) or a weak ETag with <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">W/</code> prefix if you prefer.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Last-Modified and If-Modified-Since</h2></p><p class="text-slate-300 leading-relaxed mb-4">For resources that have a clear “last modified” time (e.g. a file or a record’s <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">updated_at</code>), you can send <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">Last-Modified</code> and honor <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">If-Modified-Since</code>:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>const lastModified = new Date(record.updated_at).toUTCString();
if (req.headers["if-modified-since"] === lastModified) {
  res.writeHead(304);
  res.end();
  return;
}
res.setHeader("Last-Modified", lastModified);
res.setHeader("Cache-Control", "public, max-age=0, must-revalidate");
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">Use <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">max-age=0, must-revalidate</code> when you want clients to always revalidate but still benefit from 304 when unchanged.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">When Not to Cache</h2></p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-disc text-slate-300"><strong>User-specific or sensitive data</strong> — Prefer <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">private</code> or <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">no-store</code>.</li>
<li class="ml-4 list-disc text-slate-300"><strong>Real-time or highly dynamic data</strong> — Short <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">max-age</code> or <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">no-cache</code> + ETag.</li>
<li class="ml-4 list-disc text-slate-300"><strong>Mutable mutations (POST/PUT/DELETE)</strong> — Do not cache; use <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">no-store</code> on responses and invalidate related URLs if your design exposes them.</li></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Summary</h2></p><p class="text-slate-300 leading-relaxed mb-4">Set <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">Cache-Control</code> on every response: <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">public</code>/<code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">private</code>, plus <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">max-age</code> or <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">no-cache</code>/<code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">must-revalidate</code> as appropriate. Add <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">ETag</code> (and optionally <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">Last-Modified</code>) for conditional requests and 304 responses. In TypeScript APIs, a small helper that sets these headers per route will keep caching consistent and your APIs faster and cheaper to run.</p><p class="text-slate-300 leading-relaxed mb-4"><hr class="border-slate-700 my-6" />
