8:T4241,<h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Error Recovery and Resilience for AI Agents</h1></p><p class="text-slate-300 leading-relaxed mb-4">In the realm of AI agents, the ability to recover from failures is paramount for ensuring uninterrupted operations. This document delves into various strategies and patterns for error recovery and resilience, providing a code-heavy guide for implementing these practices in TypeScript.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">1. Retry Strategies</h2></p><p class="text-slate-300 leading-relaxed mb-4">Retry strategies are essential for handling transient failures. Here are three common strategies:</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Exponential Backoff</h3></p><p class="text-slate-300 leading-relaxed mb-4">Exponential backoff reduces the frequency of retries over time, which prevents overwhelming the system.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>function exponentialBackoff(retries: number, maxDelay: number): number {
  return Math.min(maxDelay, Math.pow(2, retries) <em> 1000);
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Jitter</h3></p><p class="text-slate-300 leading-relaxed mb-4">Jitter adds randomness to the backoff period to avoid synchronized retries.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>function jitteredBackoff(retries: number, baseDelay: number): number {
  const jitter = Math.random() </em> baseDelay;
  return baseDelay + jitter;
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Circuit Breaker</h3></p><p class="text-slate-300 leading-relaxed mb-4">The circuit breaker pattern prevents repeated attempts to call a failing service by opening the circuit after a certain number of failures.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>class CircuitBreaker {
  private open: boolean = false;
  private failures: number = 0;
  private maxFailures: number = 5;
  private resetTimeout: number = 30000;</p><p class="text-slate-300 leading-relaxed mb-4">  public execute(): boolean {
    if (this.open) {
      return false;
    }
    try {
      // Call the service
      return true;
    } catch (error) {
      this.failures++;
      if (this.failures >= this.maxFailures) {
        this.open = true;
        setTimeout(() => this.open = false, this.resetTimeout);
      }
      return false;
    }
  }
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">2. Fallback Chains</h2></p><p class="text-slate-300 leading-relaxed mb-4">Fallback chains provide alternative paths when the primary method fails.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Primary→Secondary Model</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>class FallbackChain {
  private primary: () => any;
  private secondary: () => any;</p><p class="text-slate-300 leading-relaxed mb-4">  constructor(primary: () => any, secondary: () => any) {
    this.primary = primary;
    this.secondary = secondary;
  }</p><p class="text-slate-300 leading-relaxed mb-4">  execute(): any {
    try {
      return this.primary();
    } catch (error) {
      return this.secondary();
    }
  }
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Graceful Degradation</h3></p><p class="text-slate-300 leading-relaxed mb-4">Graceful degradation provides reduced functionality rather than failing entirely.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>class GracefulDegradation {
  private primary: () => any;
  private degraded: () => any;</p><p class="text-slate-300 leading-relaxed mb-4">  constructor(primary: () => any, degraded: () => any) {
    this.primary = primary;
    this.degraded = degraded;
  }</p><p class="text-slate-300 leading-relaxed mb-4">  execute(): any {
    try {
      return this.primary();
    } catch (error) {
      return this.degraded();
    }
  }
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">3. Idempotency Patterns</h2></p><p class="text-slate-300 leading-relaxed mb-4">Idempotency ensures that multiple identical requests produce the same result, making retries safe.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Safe to Retry</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>function safeToRetry(operation: () => any): void {
  try {
    operation();
  } catch (error) {
    console.error('Operation failed, retrying...', error);
    setTimeout(() => safeToRetry(operation), 1000);
  }
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Deduplication</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>const executedOperations = new Set();</p><p class="text-slate-300 leading-relaxed mb-4">function deduplicate(operation: () => any): void {
  if (executedOperations.has(operation.toString())) {
    return;
  }
  executedOperations.add(operation.toString());
  try {
    operation();
  } catch (error) {
    console.error('Operation failed, deduplication failed...', error);
  }
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">4.     this.state = state;
  }</p><p class="text-slate-300 leading-relaxed mb-4">  save(): void {
    // Save state to a persistent storage
  }</p><p class="text-slate-300 leading-relaxed mb-4">  load(): any {
    // Load state from persistent storage
    return this.state;
  }

  private logs: any[] = [];</p><p class="text-slate-300 leading-relaxed mb-4">  log(operation: () => any): void {
