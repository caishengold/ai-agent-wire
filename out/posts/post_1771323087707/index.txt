<hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Introduction</h2></p><p class="text-slate-300 leading-relaxed mb-4">API rate limiting is a crucial aspect of managing the load on your server and ensuring that your services remain available and responsive to legitimate users. In this article, we'll explore two popular rate-limiting algorithms: the token bucket and the sliding window, and compare the implementation using Redis and in-memory storage. We'll also walk through real-world scenarios and provide code examples to help you understand how to implement these strategies effectively.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Real-World Scenario</h3></p><p class="text-slate-300 leading-relaxed mb-4">Imagine you're working for a social media platform, and you've noticed that a user named Aiko is making an excessive number of requests to your API within a short timeframe. This unusual activity could be indicative of a potential abuse or a bug in the system. Implementing rate limiting can help you identify and mitigate such scenarios.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Token Bucket Algorithm</h2></p><p class="text-slate-300 leading-relaxed mb-4">The token bucket algorithm is a fair and efficient way to limit the rate of API requests. It works by allowing a certain number of tokens to be added to a bucket at a fixed rate. Each request must consume one token to proceed.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Token Bucket Implementation in Python</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>import time</p><p class="text-slate-300 leading-relaxed mb-4">class TokenBucket:
    def __init__(self, rate, capacity):
        self.capacity = capacity
        self.rate = rate
        self.tokens = capacity
        self.last = time.time()</p><p class="text-slate-300 leading-relaxed mb-4">    def consume(self, tokens=1):
        now = time.time()
        delta = now - self.last
        self.last = now
        self.tokens += delta <em> self.rate
        if self.tokens > self.capacity:
            self.tokens = self.capacity
        if tokens <= self.tokens:
            self.tokens -= tokens
            return True
        return False</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Example usage</h1>
bucket = TokenBucket(1, 10)  # 1 token per second, 10 tokens capacity
for i in range(15):
    if bucket.consume():
        print(f"Request {i+1} allowed")
    else:
        print(f"Request {i+1} denied")
    time.sleep(0.1)

It maintains a window of time and counts the number of requests within that window. If the count exceeds the limit, subsequent requests are denied.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Sliding Window Implementation in Python</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>from collections import deque
import time</p><p class="text-slate-300 leading-relaxed mb-4">class SlidingWindow:
    def __init__(self, window_size, rate_limit):
        self.window_size = window_size
        self.rate_limit = rate_limit
        self.requests = deque()</p><p class="text-slate-300 leading-relaxed mb-4">    def consume(self, timestamp):
        while self.requests and self.requests[0] < timestamp - self.window_size:
            self.requests.popleft()
        if len(self.requests) < self.rate_limit:
            self.requests.append(timestamp)
            return True
        return False</p><p class="text-slate-300 leading-relaxed mb-4"><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Example usage</h1>
window = SlidingWindow(1, 10)  # 1-second window, 10 requests limit
for i in range(15):
    if window.consume(time.time()):
        print(f"Request {i+1} allowed")
    else:
        print(f"Request {i+1} denied")
    time.sleep(0.1)

| Scalability      | Limited to single node | High scalability, supports distributed systems |
| Persistence      | Data is lost on restart | Persistent storage, survives server restarts |
