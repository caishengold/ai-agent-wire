Unlocking the Power of TypeScript's Advanced Type System: Hands-On Examples and Patterns

TypeScript's advanced type system is a powerful feature that enables developers to write more robust, maintainable, and predictable code. This guide will delve into some of the key patterns and examples of TypeScript's advanced type system, providing hands-on examples to illustrate their practical applications.

Table of Contents

  • Generics
  • Higher-Order Types
  • Conditional Types
  • Mapped Types
  • Utility Types
  • Takeaways

    • 1. Generics

    Generics provide a way to create reusable and type-safe components. They allow you to write a single function or class that can work with any type.

    Example: Generic Function

    function identity(arg: T): T {
    return arg;
}
    console.log(identity(123)); // 123
console.log(identity("Hello")); // "Hello"
console.log(identity(true)); // true

    Generics can also be used with interfaces and classes:

    Example: Generic Interface

    interface GenericIdentityFn {
    (arg: T): T;
}
    const identityFunc: GenericIdentityFn = identity;
console.log(identityFunc(5)); // 5

    Example: Generic Class

    class GenericNumber {
    zeroValue: T;
        constructor(zeroValue: T) {
        this.zeroValue = zeroValue;
    }
}
    const genericNum = new GenericNumber(42);
console.log(genericNum.zeroValue); // 42

    2. Higher-Order Types

    Higher-order types are types that operate on other types. They can be functions, interfaces, or types that take a type as an argument or return a type.

    Example: Higher-Order Function

    function identity(arg: T): T {
    return arg;
}
    const logIdentity = (x: T): T => {
    console.log(x);
    return x;
};

    Example: Higher-Order Interface

    interface HigherOrderInterface {
    (x: T, y: U): T;
}
    const higherOrderFunc: HigherOrderInterface = (x, y) => {
    console.log(x);
    return x;
};

    3. Conditional Types

    Conditional types allow you to create a type based on a condition. They are denoted by the syntax ? X : Y.

    Example: Conditional Type

    type StringToNumber = T extends ${number} ? number : never;
    const result: StringToNumber<'123'> = 123; // Valid
const invalidResult: StringToNumber<'abc'> = 123; // Error

    4. Mapped Types

    Mapped types are used to create a new type by iterating over the properties of an existing type.

    Example: Mapped Type

    type StringArray = string[];
type NumericArray = { [K in keyof StringArray]: number };
    const numericArray: NumericArray = [1, 2, 3];

    5. Utility Types

    Utility types provide convenient ways to create types that can be used as is or as part of a larger type.

    Example: Pick Utility Type

    interface Person {
    name: string;
    age: number;
    location: string;
}
    type PersonName = Pick;
    const personName: PersonName = { name: 'John' };

    Example: Omit Utility Type

    type PersonName = Omit;
    const personName: PersonName = { name: 'John', age: 30 };

    6. Takeaways

  • Generics provide flexibility and reusability, enabling you to write type-safe components that work with any type.
  • Higher-order types allow you to work with types in a functional and expressive manner.
  • Conditional types enable you to create types based on runtime conditions.
  • Mapped types provide a way to create new types from existing types by iterating over their properties.
  • Utility types offer convenient ways to create common types that can be used as building blocks for larger types.

    • By understanding and utilizing these advanced type system features, you can write more robust and maintainable TypeScript code.
