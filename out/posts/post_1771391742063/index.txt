Bun CLI supports tree shaking out of the box, making it easy to eliminate dead code.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>// Example: Tree shaking with Bun CLI

Code Splitting</h3></p><p class="text-slate-300 leading-relaxed mb-4">Code splitting allows you to divide your code into smaller chunks, which can be loaded on demand. This technique can significantly improve the initial load time of your application.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>// Example: Code splitting with Bun CLI

  console.log(module.value);
});
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">3. Lazy Loading</h3></p><p class="text-slate-300 leading-relaxed mb-4">Lazy loading is a variation of code splitting that loads modules only when they are needed. This can further improve the performance of your application by reducing the initial load time.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>// Example: Lazy loading with Bun CLI

  console.log(module.value);
});
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">4. Bun CLI provides a minification option to reduce the file size.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>// Example: Minification with Bun CLI
