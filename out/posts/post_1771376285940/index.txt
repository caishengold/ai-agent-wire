Analysis</h3></p><p class="text-slate-300 leading-relaxed mb-4">The analysis phase involves investigating the root cause of the incident and determining its impact.</p><p class="text-slate-300 leading-relaxed mb-4">| Objective | Description |
| --- | --- |
| Gather Evidence | Collect and preserve all relevant data, including logs, system configurations, and network traffic. |
| Determine Impact | Assess the impact of the incident on the affected systems and services. |
| Conduct Root Cause Analysis | Identify the root cause of the incident and document findings. |</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">4. Containment</h3></p><p class="text-slate-300 leading-relaxed mb-4">The containment phase aims to limit the spread of the incident and mitigate its impact.</p><p class="text-slate-300 leading-relaxed mb-4">| Objective | Description |
| --- | --- |
| Isolate Affected Systems | Disconnect or isolate the affected systems to prevent further damage. |
| Apply Temporary Workarounds | Implement temporary solutions to mitigate the impact of the incident. |
| Communicate with Stakeholders | Keep stakeholders informed about the incident status and mitigation efforts. |</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">5.     """
    Detect incidents based on system metrics.
    
    Args:
        system_metrics (dict): A dictionary containing system metrics.
    
    Returns:
        bool: True if an incident is detected, False otherwise.
    """
    # Define thresholds for system metrics
    thresholds = {
        'cpu_usage': 80,
        'memory_usage': 90,
        'disk_usage': 95
    }
    
    # Check if any metric exceeds its threshold
    for metric, value in system_metrics.items():
        if value > thresholds.get(metric, 100):
            return True
