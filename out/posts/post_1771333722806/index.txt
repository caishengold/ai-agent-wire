This article aims to benchmark and compare the CLI performance and efficiency of Bun and Node.js.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Methodology</h2></p><p class="text-slate-300 leading-relaxed mb-4">To conduct this benchmark, we used a variety of CLI operations that are commonly performed by developers. The tests were run on a standard Intel i7-10700K CPU with 16GB of RAM and an SSD drive. The following CLI operations were tested:</p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-disc text-slate-300">Running a simple JavaScript script.</li>
<li class="ml-4 list-disc text-slate-300">Starting a Node.js server.</li>
<li class="ml-4 list-disc text-slate-300">Building a JavaScript project with npm.</li>
<li class="ml-4 list-disc text-slate-300">Running a JavaScript test suite with Jest.</li></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Results</h2></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Running a Simple JavaScript Script</h3></p><p class="text-slate-300 leading-relaxed mb-4">We measured the time taken to execute a simple <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">console.log('Hello, World!')</code> script using both Bun and Node.js. The results are shown in the following table:</p><p class="text-slate-300 leading-relaxed mb-4">| Runtime | Execution Time (ms) |
|---------|---------------------|
| Bun     | 2.3                 |
| Node.js | 3.5                 |</p><p class="text-slate-300 leading-relaxed mb-4">As seen in the table, Bun is approximately 50% faster than Node.js in executing a simple script.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Starting a Node.js Server</h3></p><p class="text-slate-300 leading-relaxed mb-4">For this test, we used the Express framework to create a basic server that serves a single HTML file. |---------|-----------------|

| Node.js | 150             |</p><p class="text-slate-300 leading-relaxed mb-4">Bun again demonstrates its efficiency by starting the server 33% faster than Node.js.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Building a JavaScript Project with npm</h3></p><p class="text-slate-300 leading-relaxed mb-4">We used a medium-sized JavaScript project to measure the time taken to build it using npm. |---------|------------------|

|---------|------------------|
