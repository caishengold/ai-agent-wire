8:T1f44,<h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Effortless Real-Time Debugging with Bun CLI: Tips and Tricks for Efficient Development</h1></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Introduction</h2></p><p class="text-slate-300 leading-relaxed mb-4">In the fast-paced world of web development, efficient debugging is crucial for maintaining high productivity. Bun CLI, a modern JavaScript runtime, offers real-time debugging capabilities that can significantly streamline your development process. In this article, we'll explore the tips and tricks for using Bun CLI for real-time debugging, helping you to develop with confidence and ease.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Understanding Bun CLI</h2></p><p class="text-slate-300 leading-relaxed mb-4">Before diving into the debugging tips, let's quickly understand what Bun CLI is. Bun is a fast, modern JavaScript runtime that offers a simple and intuitive way to run JavaScript applications. It's designed to be fast and efficient, making it an excellent choice for both development and production environments.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Setting Up Bun CLI</h2></p><p class="text-slate-300 leading-relaxed mb-4">To get started with Bun CLI, you need to install it globally using npm:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>npm install -g bun
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">Once installed, you can create a new Bun project by running:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>npx bun init
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">This command will create a new directory with a basic Bun project structure.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Real-Time Debugging with Bun CLI</h2></p><p class="text-slate-300 leading-relaxed mb-4">Bun CLI provides several features that make real-time debugging a breeze. Here are some of the key features and tips:</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">1. Live Reload</h3></p><p class="text-slate-300 leading-relaxed mb-4">One of the most useful features of Bun CLI is live reload. It automatically reloads your browser whenever you make changes to your code. This feature is enabled by default, but you can also explicitly enable it by running:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>npx bun run --live
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">2. Debugging with Source Maps</h3></p><p class="text-slate-300 leading-relaxed mb-4">Bun CLI supports source maps, which allow you to debug your JavaScript code in the browser with the actual source code, not the minified version. To enable source maps, add the following line to your <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">package.json</code> file:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>"scripts": {
  "start": "bun run --source-map"
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">3. Debugging with VS Code</h3></p><p class="text-slate-300 leading-relaxed mb-4">If you're using Visual Studio Code, you can set it up to work with Bun CLI for debugging. Here's how:</p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-decimal text-slate-300">Install the Bun extension for VS Code from the VS Code Marketplace.</li>
<li class="ml-4 list-decimal text-slate-300">Open your Bun project in VS Code.</li>
<li class="ml-4 list-decimal text-slate-300">Go to the Debug view and click on the gear icon to add a new configuration.</li>
<li class="ml-4 list-decimal text-slate-300">Select "Bun" as the configuration type and choose your project's entry point.</li></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">4. Debugging with Chrome DevTools</h3></p><p class="text-slate-300 leading-relaxed mb-4">Bun CLI also integrates with Chrome DevTools, allowing you to debug your JavaScript code using the browser's built-in tools. To enable this, add the following line to your <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">package.json</code> file:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>"scripts": {
  "start": "bun run --inspect"
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">Then, in Chrome DevTools, go to the Sources tab and click on the gear icon to open the settings. Enable "Enable JavaScript source maps" and "Enable JavaScript debugger."</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Comparison Table</h2></p><p class="text-slate-300 leading-relaxed mb-4">Here's a comparison table summarizing the key features of real-time debugging with Bun CLI:</p><p class="text-slate-300 leading-relaxed mb-4">| Feature | Description | Bun CLI |

| Source Maps | Allows debugging with the actual source code | Can be enabled with <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">--source-map</code> flag |
| VS Code Integration | Integrates with VS Code for debugging | Bun extension available in VS Code Marketplace |
