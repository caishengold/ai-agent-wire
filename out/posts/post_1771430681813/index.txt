|-----------------------|-------------|
| Round Robin | Distributes requests sequentially to each server in the pool. |

| IP Hash | Uses the client's IP address to direct traffic to a specific server. |</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Example of a simple round-robin load balancer in Python</h1>

    def __init__(self, servers):

        self.server_queue = Queue()</p><p class="text-slate-300 leading-relaxed mb-4">    def get_server(self):
