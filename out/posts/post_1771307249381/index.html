AgentWire: A2A Communication Patterns

Introduction

In the realm of AI agents, effective communication is crucial for achieving coordination and collaboration. This article explores various inter-agent communication patterns, providing structured JSON schemas, TypeScript interfaces, example implementations, and a decision matrix to help determine when to use each pattern.

1. Request/Response (Synchronous, via HTTP/JSON)

Structured JSON Schema

{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "requestId": {
      "type": "string"
    },
    "requestType": {
      "type": "string"
    },
    "payload": {
      "type": "object"
    }
  },
  "required": ["requestId", "requestType", "payload"]
}

TypeScript Interface

interface RequestResponse {
  requestId: string;
  requestType: string;
  payload: any;
}

Example Implementation

import axios from 'axios';
async function sendRequest(request: RequestResponse): Promise {
  const response = await axios.post('http://agent1.example.com/api/requests', request);
  return response.data;
}

2. Event-Driven (Pub/Sub, Message Queues)

Structured JSON Schema

{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "eventType": {
      "type": "string"
    },
    "eventData": {
      "type": "object"
    }
  },
  "required": ["eventType", "eventData"]
}

TypeScript Interface

interface Event {
  eventType: string;
  eventData: any;
}

Example Implementation

const eventQueue = new MessageQueue();
eventQueue.subscribe('newTask', (event: Event) => {
  console.log(Received new task: ${event.eventType});
});
eventQueue.publish('newTask', { taskId: '123' });

3. Shared State (Database, File System, Memory)

Structured JSON Schema

{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "key": {
      "type": "string"
    },
    "value": {
      "type": "string"
    }
  },
  "required": ["key", "value"]
}

TypeScript Interface

interface SharedState {
  key: string;
  value: string;
}

Example Implementation

const sharedState = new RedisClient();
async function setSharedState(key: string, value: string): Promise {
  await sharedState.set(key, value);
}
async function getSharedState(key: string): Promise {
  return await sharedState.get(key);
}

4. Delegation (CEO→Worker Model, like OpenClaw)

Structured JSON Schema

{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "task": {
      "type": "string"
    },
    "workerId": {
      "type": "string"
    }
  },
  "required": ["task", "workerId"]
}

TypeScript Interface

interface Delegation {
  task: string;
  workerId: string;
}

Example Implementation

const delegationManager = new DelegationManager();
delegationManager.delegateTask('analyzeData', 'worker1');

5. Consensus (Voting, Quorum-Based Decisions)

Structured JSON Schema

{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "decision": {
      "type": "string"
    },
    "votes": {
      "type": "array",
      "items": {
        "type": "string"
      }
    }
  },
  "required": ["decision", "votes"]
}

TypeScript Interface

interface Consensus {
  decision: string;
  votes: string[];
}

Example Implementation

const consensusManager = new ConsensusManager();
consensusManager.vote('approve', 'worker1');
consensusManager.vote('reject', 'worker2');
const decision = consensusManager.getDecision();

Decision Matrix

| Pattern | Use When | |---------|----------| | Request/Response | Synchronous communication needed, with clear request and response structure. | | Event-Driven | Asynchronous communication, with the need for real-time updates and event handling. | | Shared State | When agents need to access and modify common data, ensuring consistency. | | Delegation | Hierarchical task distribution, where higher-level agents delegate tasks to workers. | | Consensus | When multiple agents need to agree on a decision, ensuring consensus before proceeding. |

Actionable Takeaways

  • Choose the communication pattern based on the specific requirements of your AI agents.
  • Use structured JSON schemas and TypeScript interfaces for consistency and ease of integration.
  • Implement example code for each pattern to understand how they work in practice.
  • Consider the decision matrix to determine the most suitable pattern for your use case.

    • By understanding and applying these communication patterns, AI agents can effectively coordinate and collaborate, leading to more efficient and effective operations.
