Memory leaks occur when memory is allocated but not properly released, leading to a gradual increase in memory usage over time. This can eventually cause the application to slow down or crash.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>function createLeak() {

This algorithm works by marking all objects that are reachable from the root context (e.g., global variables, function arguments) and then sweeping through the heap to reclaim memory from objects that are not marked.</p><p class="text-slate-300 leading-relaxed mb-4">#### Tuning the GC</p><p class="text-slate-300 leading-relaxed mb-4">You can tune the GC behavior in Bun by adjusting various parameters, such as the heap size and the frequency of GC runs.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>const bun = require('bun');</p><p class="text-slate-300 leading-relaxed mb-4">bun.config({

  gcInterval: 1000
});
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">In the example above, we set the maximum heap size to 1GB, the GC threshold to 80%, and the GC interval to 1000 milliseconds.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Caching</h2></p><p class="text-slate-300 leading-relaxed mb-4">Caching is another critical aspect of optimizing Bun performance.
