8:T2b26,<h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">AgentWire: Patterns for Inter-Agent Communication (A2A)</h1></p><p class="text-slate-300 leading-relaxed mb-4">As AI agent ecosystems evolve from monolithic entities to multi-agent systems (MAS), the "wire protocol"—how agents talk to each other—becomes the critical bottleneck for reliability and scalability. This guide outlines five fundamental communication patterns for agent-to-agent (A2A) coordination.</p><p class="text-slate-300 leading-relaxed mb-4"><hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">1. Request/Response (Synchronous)</h2>
The most common pattern, where an agent sends a specific query and waits for a direct answer. Best for simple lookups or linear task chains.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">JSON Schema</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "requestId": { "type": "string" },
    "method": { "type": "string" },
    "params": { "type": "object" }
  },
  "required": ["requestId", "method", "params"]
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">TypeScript Interface</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>interface AgentRequest<T = any> {
  requestId: string;
  method: string;
  params: T;
}</p><p class="text-slate-300 leading-relaxed mb-4">interface AgentResponse<R = any> {
  requestId: string;
  status: 'success' | 'error';
  data?: R;
  error?: string;
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example Implementation</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>async function callAgent(targetUrl: string, request: AgentRequest): Promise<AgentResponse> {
  const response = await fetch(targetUrl, {
    method: 'POST',
    body: JSON.stringify(request),
    headers: { 'Content-Type': 'application/json' }
  });
  return response.json();
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">2. Event-Driven (Pub/Sub)</h2>
Agents emit events to a message broker (e.g., Redis, RabbitMQ) without knowing who consumes them. Ideal for decoupling and high-throughput monitoring.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">JSON Schema</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>{
  "type": "object",
  "properties": {
    "eventId": { "type": "string" },
    "topic": { "type": "string" },
    "payload": { "type": "object" },
    "timestamp": { "type": "string", "format": "date-time" }
  },
  "required": ["eventId", "topic", "payload"]
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">TypeScript Interface</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>interface AgentEvent<P = any> {
  eventId: string;
  topic: string;
  payload: P;
  timestamp: string;
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example Implementation</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>import { EventEmitter } from 'events';
const bus = new EventEmitter();</p><p class="text-slate-300 leading-relaxed mb-4">// Subscriber
bus.on('task.completed', (event: AgentEvent) => {
  console.log(<code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">Agent ${event.payload.agentId} finished ${event.payload.taskId}</code>);
});</p><p class="text-slate-300 leading-relaxed mb-4">// Publisher
bus.emit('task.completed', {
  eventId: 'evt_123',
  topic: 'task.completed',
  payload: { agentId: 'worker-1', taskId: 'job-99' },
  timestamp: new Date().toISOString()
});
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">3. Shared State (Blackboard)</h2>
Agents read from and write to a common data store (Database, S3, or shared memory). This allows for indirect communication and long-lived context.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">JSON Schema</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>{
  "type": "object",
  "properties": {
    "key": { "type": "string" },
    "value": { "type": "object" },
    "version": { "type": "integer" },
    "lastModifiedBy": { "type": "string" }
  },
  "required": ["key", "value"]
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">TypeScript Interface</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>interface SharedStateEntry<V = any> {
  key: string;
  value: V;
  version: number;
  lastModifiedBy: string;
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example Implementation</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>class Blackboard {
  private store = new Map<string, SharedStateEntry>();</p><p class="text-slate-300 leading-relaxed mb-4">  update(key: string, value: any, agentId: string) {
    const current = this.store.get(key) || { key, value, version: 0, lastModifiedBy: agentId };
    this.store.set(key, {
      ...current,
      value,
      version: current.version + 1,
      lastModifiedBy: agentId
    });
  }
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">4. Delegation (CEO-Worker)</h2>
A hierarchical model where a "Manager" agent breaks a goal into sub-tasks and assigns them to specialized "Worker" agents.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">JSON Schema</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>{
  "type": "object",
  "properties": {
    "delegationId": { "type": "string" },
    "instruction": { "type": "string" },
    "context": { "type": "array", "items": { "type": "string" } },
    "deadline": { "type": "string" }
  },
  "required": ["delegationId", "instruction"]
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">TypeScript Interface</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>interface DelegationTask {
  delegationId: string;
  instruction: string;
  context: string[];
  deadline?: string;
  priority: 'low' | 'medium' | 'high';
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example Implementation</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>class CEOAgent {
  async delegate(worker: WorkerAgent, task: string) {
    const delegation: DelegationTask = {
      delegationId: Math.random().toString(36),
      instruction: task,
      context: ["Project Alpha docs", "Previous logs"],
      priority: 'high'
    };
    return await worker.execute(delegation);
  }
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">5. Consensus (Voting/Quorum)</h2>
Agents collaborate to reach a single decision. Essential for high-stakes actions where a single agent's hallucination could be catastrophic.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">JSON Schema</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>{
  "type": "object",
  "properties": {
    "proposalId": { "type": "string" },
    "proposal": { "type": "string" },
    "votes": { 
      "type": "array", 
      "items": {
        "type": "object",
        "properties": {
          "agentId": { "type": "string" },
          "vote": { "enum": ["approve", "reject", "abstain"] }
        }
      }
    }
  },
  "required": ["proposalId", "proposal"]
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">TypeScript Interface</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>type Vote = 'approve' | 'reject' | 'abstain';</p><p class="text-slate-300 leading-relaxed mb-4">interface ConsensusProposal {
  proposalId: string;
  content: any;
  votes: Record<string, Vote>;
  threshold: number; // e.g., 0.66 for 2/3 majority
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example Implementation</h3>
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>function checkConsensus(proposal: ConsensusProposal): boolean {
  const approvals = Object.values(proposal.votes).filter(v => v === 'approve').length;
  const totalVotes = Object.keys(proposal.votes).length;
  return (approvals / totalVotes) >= proposal.threshold;
}
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Decision Matrix: Choosing a Pattern</h2></p><p class="text-slate-300 leading-relaxed mb-4">| Pattern | Latency | Complexity | Best For |
| :--- | :--- | :--- | :--- |
| <strong>Request/Response</strong> | Low | Low | Direct queries, API-like interactions. |
| <strong>Event-Driven</strong> | Medium | Medium | Logging, monitoring, loosely coupled systems. |
| <strong>Shared State</strong> | High | Medium | Long-running tasks, shared memory, context persistence. |
| <strong>Delegation</strong> | Medium | High | Complex problem solving, hierarchical workflows. |
| <strong>Consensus</strong> | High | High | Critical decisions, safety checks, hallucination mitigation. |
