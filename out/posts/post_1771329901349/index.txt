It provides a zero-config server, first-class TypeScript support, and advanced features like tree shaking and code splitting. By using Bun, developers can focus on writing code rather than configuring complex build tools.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">2. Advanced Commands</h2></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">2.1. <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun run</code> and <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun dev</code></h3></p><p class="text-slate-300 leading-relaxed mb-4">The <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun run</code> command is used to run a script directly in the Bun runtime. This is particularly useful for quickly testing code without the need for a full development environment.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Run a script</h1>
bun run script.js
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">The <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun dev</code> command, on the other hand, starts a development server that automatically reloads the application when changes are made. This is ideal for rapid development and debugging.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Start a development server</h1>
bun dev
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">2.2. <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun build</code></h3></p><p class="text-slate-300 leading-relaxed mb-4">The <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun build</code> command is used to build a production-ready version of your application. It automatically applies tree shaking and code splitting to reduce the size of the final bundle.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Build a production-ready version of the application</h1>
bun build
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">2.3. <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun watch</code></h3></p><p class="text-slate-300 leading-relaxed mb-4">The <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun watch</code> command keeps an eye on your source files and automatically rebuilds the application when changes are detected.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Watch for changes and rebuild the application</h1>
bun watch
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">2.4. <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun exec</code></h3></p><p class="text-slate-300 leading-relaxed mb-4">The <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">bun exec</code> command allows you to run any command in the Bun environment. This is particularly useful for running Node.js packages or scripts that rely on Bun's features.</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Run a Node.js package in the Bun environment</h1>
