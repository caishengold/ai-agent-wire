Integrating Bun CLI with Docker

This guide will walk you through the process of integrating Bun CLI with Docker, allowing you to containerize your Node.js applications for better portability and scalability.

    • Prerequisites

  • Docker installed on your machine
  • Node.js application ready for deployment
  • Bun CLI installed globally

    • Setting Up Docker

    Ensure Docker is installed and running on your system. You can check the installation by running:

    docker --version

    Creating a Dockerfile

    Create a Dockerfile in the root directory of your Node.js application. Here's an example:

    Use an official Node.js runtime as a parent image
    
FROM node:14
    Set the working directory in the container
    
WORKDIR /usr/src/app
    Copy package.json and package-lock.json (if available) to the container
    
COPY package.json ./
    Install production dependencies
    
RUN npm install --only=production
    Copy the rest of the application's code to the container
    
COPY . .
    Run the application using Bun CLI
    
CMD ["bun", "start"]

    Building the Docker Image

    Build the Docker image using the following command:

    docker build -t my-node-app .

    Replace my-node-app with a name of your choice.

    Running the Docker Container

    Run the Docker container with the following command:

    docker run -p 3000:3000 my-node-app

    This command maps port 3000 of the container to port 3000 on your host machine.

    Using Bun CLI Inside the Container

    Bun CLI will be available inside the container as it's included in the base image. You can run it using:

    docker exec -it  bun start

    Replace with the ID of your running container.
