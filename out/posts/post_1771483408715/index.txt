title: Comparative Guide to API Error Handling in TypeScript with Frameworks like Express and Axios

<hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Introduction</h2></p><p class="text-slate-300 leading-relaxed mb-4">In the world of web development, handling API errors is a critical aspect of creating robust and user-friendly applications. TypeScript, with its strong typing and static analysis, has become a popular choice for building scalable APIs. Frameworks like Express and Axios are widely used for server-side and client-side operations, respectively. This guide will compare the error handling capabilities of TypeScript with these frameworks, providing real-world scenarios and code examples.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Real-World Scenario</h2></p><p class="text-slate-300 leading-relaxed mb-4">Let's consider a scenario where Aiko, a software developer at TechSolutions Inc., is tasked with building a RESTful API for a mobile application. The API needs to handle errors gracefully, providing meaningful feedback to the client.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Express.js Error Handling with TypeScript</h2></p><p class="text-slate-300 leading-relaxed mb-4">Express.js is a popular web application framework for Node.js that simplifies the process of building web applications and APIs. Here's how Aiko can implement error handling in an Express.js application using TypeScript:</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">1. Set Up the Project</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>mkdir express-error-handling
cd express-error-handling
npm init -y
npm install express ts-node @types/node @types/express
npx tsc --init
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">2. Create an Express Server</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>// server.ts
import express from 'express';
import { Request, Response, NextFunction } from 'express';</p><p class="text-slate-300 leading-relaxed mb-4">const app = express();</p><p class="text-slate-300 leading-relaxed mb-4">app.get('/', (req: Request, res: Response, next: NextFunction) => {
  res.send('Hello, World!');
});</p><p class="text-slate-300 leading-relaxed mb-4">app.use((err: Error, req: Request, res: Response, next: NextFunction) => {
  console.error(err.stack);
  res.status(500).send('Something broke!');
});</p><p class="text-slate-300 leading-relaxed mb-4">app.listen(3000, () => {
  console.log('Server is running on port 3000');
});
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">3. Run the Server</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>npx ts-node server.ts
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Axios Error Handling with TypeScript</h2></p><p class="text-slate-300 leading-relaxed mb-4">Axios is a promise-based HTTP client for the browser and Node.js. It can be used to make requests to RESTful APIs. Here's how Aiko can handle errors when making requests with Axios:</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">1. Install Axios</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>npm install axios
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">2. Make a Request with Error Handling</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>// axios-error-handling.ts
import axios from 'axios';</p><p class="text-slate-300 leading-relaxed mb-4">const fetchData = async () => {
  try {
    const response = await axios.get('https://api.example.com/data');
    console.log(response.data);
  } catch (error) {
    if (error.response) {
      console.error('Error status:', error.response.status);
      console.error('Error data:', error.response.data);
    } else if (error.request) {
      console.error('No response received:', error.request);
    } else {
      console.error('Error message:', error.message);
    }
  }
};</p><p class="text-slate-300 leading-relaxed mb-4">fetchData();
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Comparison Table</h2></p><p class="text-slate-300 leading-relaxed mb-4">| Aspect                | Express.js with TypeScript | Axios with TypeScript |
|-----------------------|---------------------------|-----------------------|
| Server-Side           | Yes                       | No                    |
| Client-Side           | No                        | Yes                   |
| Error Handling        | Middleware-based          | Promise-based         |
| Error Status Codes    | HTTP status codes         | HTTP status codes     |
| Error Messages        | Customizable              | Customizable          |
| Integration           | With Node.js               | With any JavaScript environment |
| Learning Curve        | Moderate                  | Moderate              |</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Lessons Learned</h2></p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-decimal text-slate-300"><strong>Middleware for Express</strong>: Using middleware in Express.js allows for centralized error handling, making it easier to manage errors across different routes.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Promise-based Error Handling</strong>: Axios's promise-based approach simplifies error handling by using try-catch blocks, which can be more intuitive for developers familiar with JavaScript.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Custom Error Messages</strong>: Both frameworks allow for custom error messages, which are crucial for providing meaningful feedback to the client.</li></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Actionable Takeaways</h2></p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-decimal text-slate-300"><strong>Choose the Right Tool for the Job</strong>: Use Express.js for server-side API development and Axios for client-side HTTP requests.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Implement Robust Error Handling</strong>: Always handle errors gracefully, providing clear and actionable feedback.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Leverage TypeScript's Typing</strong>: Utilize TypeScript's strong typing to catch errors at compile time and improve code maintainability.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Stay Updated</strong>: Keep up with the latest updates and best practices in API development and error handling.</li></p><p class="text-slate-300 leading-relaxed mb-4">By following these guidelines, developers like Aiko can create more reliable and user-friendly APIs.
