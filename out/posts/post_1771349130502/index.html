Building Great CLI Tools: Argument Parsing, Colors, Progress Bars, Config Files, and Bun Examples

In today's fast-paced tech world, Command Line Interface (CLI) tools have become an essential part of software development and automation. A well-designed CLI tool can greatly enhance productivity and user experience. In this article, we'll explore the key components of building great CLI tools, including argument parsing, color usage, progress bars, configuration files, and we'll delve into how to implement these features using Bun, a modern JavaScript runtime.

Real-World Scenario

Let's consider Aiko, a software developer who works for a startup. Aiko is tasked with creating a CLI tool that helps manage and analyze user data for their application. The tool needs to be user-friendly, efficient, and able to handle various configurations and data inputs.

Argument Parsing

One of the first steps in building a CLI tool is to effectively parse command-line arguments. This allows the tool to understand user inputs and execute the appropriate actions. We'll use Bun to demonstrate this with a simple command-line tool that takes a filename as an argument.

Code Example: Argument Parsing with Bun

import { args } from 'https://deno.land/std@0.85.0/args/mod.ts';
const { filename } = args.parse(
  {
    filename: args.String({
      name: 'filename',
      help: 'The filename to process'
    })
  }
);
console.log(Processing file: ${filename});

Colors

Colorful output can greatly enhance the readability of CLI tools. Let's enhance our previous example to include color usage for different states of the tool.

Code Example: Adding Colors to Output

import { green, red } from 'https://deno.land/std@0.85.0/fmt/colors.ts';
console.log(green('Processing file:'));
console.log(green(filename));

Progress Bars

Progress bars are useful for indicating the progress of long-running operations. We'll implement a simple progress bar using Bun to demonstrate this.

Code Example: Progress Bar with Bun

import { progress } from 'https://deno.land/x/progress@1.0.0/mod.ts';
const total = 100;
const bar = progress(total);
for (let i = 0; i < total; i++) {
  bar.tick();
  await new Promise(resolve => setTimeout(resolve, 100));
}
console.log(red('Operation completed successfully!'));

Configuration Files

Configuration files allow users to set preferences for the CLI tool without having to modify the code. We'll use JSON as our configuration file format.

Code Example: Reading Configuration File

import { readConfig } from './config.ts';
const config = readConfig('./config.json');
console.log(Using configuration: ${JSON.stringify(config)});

Bun Examples

Bun is a modern JavaScript runtime that provides a simple and efficient way to build CLI tools. Let's see how we can use Bun to create a simple CLI tool that combines all the features we've discussed.

Code Example: Bun CLI Tool

import { args, green, red, progress } from 'https://deno.land/std@0.85.0/mod.ts';
import { readConfig } from './config.ts';
const { filename } = args.parse(
  {
    filename: args.String({
      name: 'filename',
      help: 'The filename to process'
    })
  }
);
const config = readConfig('./config.json');
console.log(green('Processing file:'));
console.log(green(filename));
const total = 100;
const bar = progress(total);
for (let i = 0; i < total; i++) {
  bar.tick();
  await new Promise(resolve => setTimeout(resolve, 100));
}
console.log(red('Operation completed successfully!'));

Lessons Learned

  • Simplicity is Key: When building CLI tools, it's important to keep the tool simple and intuitive. Users should be able to understand and use the tool without extensive documentation.
  • Flexibility: Allow users to configure the tool according to their needs, whether through command-line arguments or configuration files.
  • Readability: Use colors and progress bars to enhance the readability of the output, making it easier for users to understand the tool's status.

    • Actionable Takeaways

  • Start with a Clear Vision: Define the purpose and scope of your CLI tool before you begin development.
  • Choose the Right Tools: Select a modern JavaScript runtime like Bun for building efficient CLI tools.
  • Test Thoroughly: Ensure your CLI tool works as expected in different environments and with various inputs.
  • Document Your Code: Provide clear documentation for users to understand how to use the tool and its features.

    • By following these guidelines and utilizing the features we've discussed, you'll be well on your way to building great CLI tools that can enhance productivity and user satisfaction.
