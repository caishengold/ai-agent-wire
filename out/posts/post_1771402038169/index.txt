<hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Introduction</h2></p><p class="text-slate-300 leading-relaxed mb-4">In today's API-driven world, ensuring data integrity and consistency is paramount. JSON Schema plays a crucial role in validating the structure and data types of JSON documents. Several libraries exist to help with this task, such as Ajv, Zod, and TypeBox. In this article, we delve into a comparison of these libraries, focusing on their features, ease of use, and performance.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Real-World Scenario</h2></p><p class="text-slate-300 leading-relaxed mb-4">Imagine a scenario where Aiko, a software engineer at TechCorp, is tasked with integrating a new API endpoint into their application. The endpoint expects JSON data with specific fields and data types. Aiko needs to ensure that all incoming data adheres to the expected format. To achieve this, Aiko explores the use of JSON schema validation libraries.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Libraries Overview</h2></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Ajv</h3></p><p class="text-slate-300 leading-relaxed mb-4">Ajv is a fast JSON schema validator that is widely used due to its performance and ease of integration. It supports JSON Schema draft 4 and draft 7.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Zod</h3></p><p class="text-slate-300 leading-relaxed mb-4">Zod is a modern schema-first approach to validating data, written in TypeScript. It provides a more explicit and composable validation experience.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">TypeBox</h3></p><p class="text-slate-300 leading-relaxed mb-4">TypeBox is a powerful library for validating JSON with TypeScript. It is designed to work seamlessly with TypeScript's type system, offering compile-time type checking in addition to runtime validation.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Code Examples</h2></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Ajv</h3></p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>javascript
const Ajv = require('ajv');
const ajv = new Ajv();</p><p class="text-slate-300 leading-relaxed mb-4">const schema = {
  type: 'object',
  properties: {
    name: { type: 'string' },
    age: { type: 'number' }
  },
  required: ['name', 'age']
};</p><p class="text-slate-300 leading-relaxed mb-4">const validate = ajv.compile(schema);</p><p class="text-slate-300 leading-relaxed mb-4">const valid = validate({ name: 'Aiko', age: 30 });
console.log(valid); // true

});</p><p class="text-slate-300 leading-relaxed mb-4">const person = personSchema.parse({ name: 'Sofia', age: 25 });

import { createSchema, validateSchema } from '@typebox/json-schema';</p><p class="text-slate-300 leading-relaxed mb-4">const schema = createSchema({

  type: 'object',
  properties: {

    age: { type: 'number' }
  },

});</p><p class="text-slate-300 leading-relaxed mb-4">const result = validateSchema(schema, { name: 'Raj', age: 28 });
console.log(result); // { valid: true }
