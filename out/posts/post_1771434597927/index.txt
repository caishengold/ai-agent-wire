8:T2246,<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code><h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Full-Text Search with SQLite FTS5: Setup, Indexing, Ranking, and a Real-World Example</h1></p><p class="text-slate-300 leading-relaxed mb-4">In today's digital age, the ability to efficiently search through large volumes of text is crucial. SQLite, a widely-used lightweight database, offers a powerful full-text search (FTS) extension called FTS5. This guide will walk you through setting up FTS5, indexing your data, ranking results, and provide a real-world example to illustrate its practical application.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Setting Up SQLite FTS5</h2></p><p class="text-slate-300 leading-relaxed mb-4">SQLite FTS5 is an extension that allows you to perform full-text searches on text data stored in SQLite databases. To get started, you need to have SQLite installed on your system. Once you have SQLite, you can enable FTS5 by creating a virtual table using the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">CREATE VIRTUAL TABLE</code> statement.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example: Creating an FTS5 Table</h3></p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
CREATE VIRTUAL TABLE fts_documents USING fts5(
    title,
    content,
    tokenize = "simple"
);
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
In this example, <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">fts_documents</code> is the name of the virtual table, and <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">title</code> and <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">content</code> are the columns that will be indexed for full-text search. The <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">tokenize = "simple"</code> option specifies a simple tokenizer that splits text into words based on whitespace.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Indexing Your Data</h2></p><p class="text-slate-300 leading-relaxed mb-4">After setting up the FTS5 table, you need to index your data. This involves inserting rows into the virtual table with the text you want to search.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example: Inserting Data into FTS5 Table</h3></p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
INSERT INTO fts_documents(title, content) VALUES('Introduction to SQLite', 'SQLite is a lightweight database...');
INSERT INTO fts_documents(title, content) VALUES('Advanced SQLite Techniques', 'This document covers advanced SQLite features...');
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
Each row you insert into the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">fts_documents</code> table becomes part of the full-text index, making it searchable.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Ranking Results</h2></p><p class="text-slate-300 leading-relaxed mb-4">Once your data is indexed, you can perform searches using the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">MATCH</code> operator. The ranking of search results is based on the relevance of the matched words to the search query.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example: Searching with FTS5</h3></p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
SELECT title, content FROM fts_documents WHERE fts_documents MATCH 'sqlite';
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
This query will return all documents that contain the word "sqlite". The results are ranked based on the number of matched words and their proximity to each other.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Real-World Example: Aiko's Bookstore</h2></p><p class="text-slate-300 leading-relaxed mb-4">Let's consider a real-world scenario where Aiko runs a bookstore. She wants to implement a search feature on her website that allows customers to find books by title or content.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Setup</h3></p><p class="text-slate-300 leading-relaxed mb-4">Aiko sets up an FTS5 table in her SQLite database to index book titles and descriptions.</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
CREATE VIRTUAL TABLE fts_books USING fts5(
    title,
    description,
    tokenize = "simple"
);
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
<h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Indexing Data</h3></p><p class="text-slate-300 leading-relaxed mb-4">Aiko populates the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">fts_books</code> table with book data.</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
INSERT INTO fts_books(title, description) VALUES('The Art of Computer Programming', 'A comprehensive guide to computer programming...');
INSERT INTO fts_books(title, description) VALUES('Clean Code', 'A guide to writing clean and maintainable code...');
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
<h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Searching</h3></p><p class="text-slate-300 leading-relaxed mb-4">When a customer searches for "programming", Aiko's website queries the FTS5 table.</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
SELECT title, description FROM fts_books WHERE fts_books MATCH 'programming';
