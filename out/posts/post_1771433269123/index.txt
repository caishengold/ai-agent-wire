title: "Advanced SQLite: CTEs, Window Functions, Generated Columns, JSON Functions, and Real Query Examples"
date: "2026-02-16"
author: "Aiko Chen"
<hr class="border-slate-700 my-6" /></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Introduction</h2></p><p class="text-slate-300 leading-relaxed mb-4">SQLite is a powerful and widely-used database engine that offers a variety of advanced features for data manipulation and analysis. In this article, we will delve into some of the more sophisticated features of SQLite, including Common Table Expressions (CTEs), window functions, generated columns, and JSON functions. We will illustrate these features with real-world scenarios and provide code examples for each.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Real-World Scenario: Sales Analysis</h2></p><p class="text-slate-300 leading-relaxed mb-4">Let's consider a scenario where Raj, a sales manager at a tech company, needs to analyze the sales performance of his team. He has access to a SQLite database containing the following tables:</p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-disc text-slate-300"><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">employees</code> (employee_id, name, department)</li>
<li class="ml-4 list-disc text-slate-300"><code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">sales</code> (sale_id, employee_id, amount, sale_date)</li></p><p class="text-slate-300 leading-relaxed mb-4">Raj wants to understand the average sales amount per department, rank his team members by total sales, and extract information from JSON data stored in the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">sales</code> table.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Common Table Expressions (CTEs)</h2></p><p class="text-slate-300 leading-relaxed mb-4">CTEs allow us to perform complex queries by breaking them down into more manageable parts. Here's an example of how Raj can use a CTE to calculate the average sales amount per department:</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
WITH DepartmentSales AS (
    SELECT department, AVG(amount) AS avg_sales
    FROM sales
    GROUP BY department
)
SELECT department, avg_sales
FROM DepartmentSales;
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
<h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Window Functions</h2></p><p class="text-slate-300 leading-relaxed mb-4">Window functions enable us to perform calculations across a set of rows that are somehow related to the current row. Raj can use a window function to rank his team members by total sales:</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
WITH RankedSales AS (
    SELECT employee_id, name, SUM(amount) AS total_sales,
           RANK() OVER (ORDER BY SUM(amount) DESC) AS sales_rank
    FROM employees
    JOIN sales ON employees.employee_id = sales.employee_id
    GROUP BY employee_id, name
)
SELECT employee_id, name, total_sales, sales_rank
FROM RankedSales;
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
<h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Generated Columns</h2></p><p class="text-slate-300 leading-relaxed mb-4">Generated columns are columns that are calculated from an expression and stored in the database. This can be useful for storing derived data, such as the year of a sale:</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
CREATE TABLE sales (
    sale_id INTEGER PRIMARY KEY,
    employee_id INTEGER,
    amount REAL,
    sale_date DATE,
    sale_year INTEGER AS (strftime('%Y', sale_date))
);
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
<h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">JSON Functions</h2></p><p class="text-slate-300 leading-relaxed mb-4">SQLite has built-in support for JSON data. Raj can extract information from a JSON field in the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">sales</code> table using the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">json_extract</code> function:</p><p class="text-slate-300 leading-relaxed mb-4"></code></pre>sql
SELECT sale_id, json_extract(sales_data, '$.customer_id') AS customer_id
FROM sales;
<pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>
<h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Comparison Table</h2></p><p class="text-slate-300 leading-relaxed mb-4">| Feature                | Description                                                                 | Example                                                                 |
|------------------------|-----------------------------------------------------------------------------|--------------------------------------------------------------------------|
| CTEs                   | Allows breaking down complex queries into manageable parts.                  | Calculate average sales per department.                                 |
| Window Functions       | Perform calculations across a set of rows related to the current row.        | Rank team members by total sales.                                        |
| Generated Columns      | Store calculated data in a column.                                         | Store year of sale as a generated column.                                 |
| JSON Functions         | Extract and manipulate JSON data.                                         | Extract customer ID from a JSON field in the sales table.                |
|                       |                                                                             |                                                                          |
|                       |                                                                             |                                                                          |</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Lessons Learned</h2></p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-disc text-slate-300">CTEs can simplify complex queries and improve readability.</li>
<li class="ml-4 list-disc text-slate-300">Window functions provide powerful capabilities for advanced analytics.</li>
<li class="ml-4 list-disc text-slate-300">Generated columns can store derived data without additional calculations.</li>
<li class="ml-4 list-disc text-slate-300">JSON functions enable working with JSON data directly in SQLite.</li></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Actionable Takeaways</h2></p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-decimal text-slate-300"><strong>Utilize CTEs for Simplified Queries</strong>: Break down complex queries into smaller, more readable parts using CTEs.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Implement Window Functions for Advanced Analytics</strong>: Use window functions to perform calculations across sets of rows for advanced analytics.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Leverage Generated Columns for Efficiency</strong>: Store derived data in generated columns to avoid recalculations.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Work with JSON Data Using SQLite Functions</strong>: Take advantage of JSON functions to extract and manipulate JSON data stored in SQLite.</li>
<li class="ml-4 list-decimal text-slate-300"><strong>Practice and Experiment</strong>: Explore these features in your own projects to gain a deeper understanding and apply them effectively.</li></p><p class="text-slate-300 leading-relaxed mb-4">By mastering these advanced features, Raj and other data professionals can unlock the full potential of SQLite for their data analysis needs.
