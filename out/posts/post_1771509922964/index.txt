It allows developers to write modular code that is both type-safe and easy to maintain. TypeScript modules are defined using the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">import</code> and <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">export</code> statements.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">TypeScript Module Syntax</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>// File: myModule.ts

import { greet } from './myModule';</p><p class="text-slate-300 leading-relaxed mb-4">console.log(greet('World'));

<li class="ml-4 list-disc text-slate-300"><strong>Tooling Support</strong>: TypeScript provides powerful tooling support, including intellisense, type checking, and refactoring tools.</li>
<li class="ml-4 list-disc text-slate-300"><strong>Interoperability</strong>: TypeScript can be transpiled to JavaScript, allowing it to be used with any JavaScript environment.</li></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">ECMAScript Modules (ESM)</h2></p><p class="text-slate-300 leading-relaxed mb-4">ESM is a native module system introduced in ECMAScript 2015 (ES6). It provides a simple and efficient way to organize code into modules, enabling better code reuse and maintainability.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">ESM Module Syntax</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>// File: myModule.js

import { greet } from './myModule';</p><p class="text-slate-300 leading-relaxed mb-4">console.log(greet('World'));
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">ESM Module Features</h3></p><p class="text-slate-300 leading-relaxed mb-4"><li class="ml-4 list-disc text-slate-300"><strong>Native Support</strong>: ESM is natively supported by modern browsers and Node.js, eliminating the need for transpilation.</li>
<li class="ml-4 list-disc text-slate-300"><strong>Performance</strong>: ESM modules are loaded asynchronously, which can improve the performance of web applications.</li>
<li class="ml-4 list-disc text-slate-300"><strong>Interoperability</strong>: ESM can be used with any JavaScript environment that supports it, including Node.js and modern browsers.</li></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Comparison Table</h2></p><p class="text-slate-300 leading-relaxed mb-4">| Feature         | TypeScript Modules | ECMAScript Modules |

| Performance     | Transpiled to JavaScript | Native support, async loading |
