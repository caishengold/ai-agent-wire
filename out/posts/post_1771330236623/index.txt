8:T1c35,<h1 class="text-2xl font-bold text-slate-100 mt-8 mb-4">Customizing Bun CLI Commands for Improved Workflow Efficiency</h1></p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Introduction</h2></p><p class="text-slate-300 leading-relaxed mb-4">Bun, a modern JavaScript runtime, has gained popularity for its speed and ease of use. Its command-line interface (CLI) offers a variety of commands that streamline development workflows. However, by default, these commands may not fit every project's needs. This article explores how to customize Bun CLI commands to enhance workflow efficiency.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Custom Commands Overview</h2></p><p class="text-slate-300 leading-relaxed mb-4">Customizing Bun CLI commands involves creating wrapper scripts or extending existing commands. This allows developers to tailor the commands to their specific workflows, reducing the number of steps and improving productivity.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Setting Up Custom Commands</h2></p><p class="text-slate-300 leading-relaxed mb-4">To get started with custom commands, you need to create a <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">.bunrc</code> file in your project's root directory. This file will contain the configurations for your custom commands.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Step 1: Create a <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">.bunrc</code> File</h3></p><p class="text-slate-300 leading-relaxed mb-4">Open a terminal and navigate to your project's root directory. Then, create a <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">.bunrc</code> file using a text editor:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>nano .bunrc
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Step 2: Define Custom Commands</h3></p><p class="text-slate-300 leading-relaxed mb-4">Inside the <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">.bunrc</code> file, you can define custom commands using the following format:</p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>const { command } = require('bun');</p><p class="text-slate-300 leading-relaxed mb-4">command('start-dev', {
  usage: 'start development server',
  fn() {
    bun('node', './dev-server.js');
  },
});
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">In this example, we've created a custom command <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">start-dev</code> that runs a development server by executing <code class="bg-slate-700/50 px-1.5 py-0.5 rounded text-cyan-300 text-sm">node ./dev-server.js</code>.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Custom Command Examples</h2></p><p class="text-slate-300 leading-relaxed mb-4">Let's dive into some practical examples of custom commands that can improve your workflow.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example 1: Linting and Formatting</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>const { command } = require('bun');</p><p class="text-slate-300 leading-relaxed mb-4">command('lint', {
  usage: 'run linter on all files',
  fn() {
    bun('eslint', '<em>.js', '</em>.jsx', '<em>.ts', '</em>.tsx');
  },
});</p><p class="text-slate-300 leading-relaxed mb-4">command('format', {
  usage: 'format all files with prettier',
  fn() {
    bun('prettier', '--write', '<em>.js', '</em>.jsx', '<em>.ts', '</em>.tsx');
  },
});
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">With these commands, you can quickly run ESLint and Prettier on your project with a single command.</p><p class="text-slate-300 leading-relaxed mb-4"><h3 class="text-lg font-semibold text-slate-100 mt-6 mb-2">Example 2: Deploying to Production</h3></p><p class="text-slate-300 leading-relaxed mb-4"><pre class="bg-slate-950 border border-slate-700 rounded-lg p-4 my-4 overflow-x-auto text-sm"><code>const { command } = require('bun');</p><p class="text-slate-300 leading-relaxed mb-4">command('deploy', {

  },
});
</code></pre></p><p class="text-slate-300 leading-relaxed mb-4">This custom command automates the process of deploying your application to production by pushing to the repository, building the project, and starting the server on the remote server.</p><p class="text-slate-300 leading-relaxed mb-4"><h2 class="text-xl font-bold text-slate-100 mt-8 mb-3">Comparison Table</h2></p><p class="text-slate-300 leading-relaxed mb-4">| Command | Usage | Description |
