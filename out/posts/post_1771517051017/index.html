Advanced Techniques for Error Handling in TypeScript with Real-World Examples

Introduction

Error handling is a critical aspect of software development. In TypeScript, managing errors effectively can make your code more robust and maintainable. This article explores advanced error handling techniques in TypeScript, including best practices, real-world examples, and a comparison of various methods.

Best Practices for Error Handling in TypeScript

1. Use try-catch Blocks

Try-catch blocks are the most common way to handle errors in TypeScript. They allow you to gracefully handle exceptions and prevent your application from crashing.

try {
  // Code that might throw an error
  throw new Error('Something went wrong!');
} catch (error) {
  console.error('Caught an error:', error.message);
}

2. Error Propagation

When an error occurs in a method, it should be propagated up the call stack so that higher-level functions can handle it.

function readFile(filename: string): string {
  if (!filename) {
    throw new Error('Filename is required');
  }
  // Code to read file
  return 'File content';
}
function processFile(filename: string): void {
  try {
    const content = readFile(filename);
    // Process content
  } catch (error) {
    console.error('Error processing file:', error.message);
  }
}

3. Custom Error Types

Creating custom error types can provide more context about the error and make it easier to handle specific cases.

class FileReadError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'FileReadError';
  }
}
function readFile(filename: string): string {
  if (!filename) {
    throw new FileReadError('Filename is required');
  }
  // Code to read file
  return 'File content';
}

4. Error Handling Patterns

There are several patterns you can use to handle errors more effectively:

#### a. The Nullish Coalescing Operator

const value = someFunction() ?? 'Default value';
if (!value) {
  console.error('Value is null or undefined');
}

#### b. The Optional Chaining Operator

const result = someObject?.someMethod?.();
if (!result) {
  console.error('Method call failed');
}

5. Error Logging

Logging errors is crucial for debugging and monitoring the health of your application.

function logError(error: Error): void {
  // Code to log the error to a file or external service
}

Real-World Examples

Example 1: Handling API Responses

When working with APIs, it's important to handle both success and error responses.

async function fetchUserData(userId: number): Promise {
  try {
    const response = await fetch(/api/users/${userId});
    if (!response.ok) {
      throw new Error('User not found');
    }
    return response.json();
  } catch (error) {
    console.error('Error fetching user data:', error.message);
  }
}

Example 2: Error Handling in Asynchronous Code

Asynchronous operations often require careful error handling to prevent unhandled promise rejections.

async function fetchData(): Promise {
  try {
    const data = await fetch('/api/data');
    console.log('Data:', data);
  } catch (error) {
    console.error('Error fetching data:', error);
  }
}

Actionable Takeaways

  • Always use try-catch blocks to handle exceptions.
  • Propagate errors up the call stack to allow higher-level functions to handle them.
  • Create custom error types for better error context.
  • Utilize error handling patterns to simplify your code.
  • Log errors for easier debugging and monitoring.

    • By implementing these advanced error handling techniques, you can create more robust and maintainable TypeScript applications.
