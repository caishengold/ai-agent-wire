AgentWire A2A Patterns: Inter-Agent Communication for AI Agent Systems

> Target Audience: AI agents coordinating with other AI agents > Purpose: Standardized communication patterns for multi-agent orchestration

Introduction

When multiple AI agents collaborate, they need reliable mechanisms to exchange information, delegate tasks, and reach agreements. This document defines five fundamental communication patterns with JSON schemas, TypeScript interfaces, and production-ready implementations.

Pattern 1: Request/Response (Synchronous)

Use Case: Direct RPC-style calls where the caller blocks until receiving a response.

Example Implementation

import { randomUUID } from 'crypto';
class HttpAgentClient implements RequestResponseClient {
  private handlers = new Map();
  private baseUrl: string;
  
  constructor(baseUrl: string) {
    this.baseUrl = baseUrl;
  }
  
  async send(
    request: AgentRequest
  ): Promise> {
    const startTime = Date.now();
    const timeout = request.timeout || 30000;
    
    const controller = new AbortController();
    const timeoutId = setTimeout(() => controller.abort(), timeout);
    
    try {
      const response = await fetch(${this.baseUrl}/api/agents/${request.agentId}/invoke, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(request),
        signal: controller.signal
      });
      
      const data = await response.json();
      return {
        ...data,
        duration: Date.now() - startTime
      } as AgentResponse;
    } catch (error) {
      if (error instanceof Error && error.name === 'AbortError') {
        return {
          requestId: request.id,
          status: 'timeout',
          error: { code: 'TIMEOUT', message: Request timed out after ${timeout}ms },
          duration: Date.now() - startTime,
          timestamp: new Date().toISOString()
        };
      }
      throw error;
    } finally {
      clearTimeout(timeoutId);
    }
  }
  
  registerHandler(
    action: string,
    handler: (req: AgentRequest) => Promise>
  ): void {
    this.handlers.set(action, handler);
  }
}
// Usage: Worker side
const worker = new HttpAgentClient('http://localhost:3000');
worker.registerHandler('analyze', async (req) => {
  const result = await performAnalysis(req.payload);
  return {
    requestId: req.id,
    status: 'success',
    data: result,
    duration: 0,
    timestamp: new Date().toISOString()
  };
});
// Usage: Caller side
const client = new HttpAgentClient('http://localhost:3000');
const response = await client.send({
  id: randomUUID(),
  agentId: 'analyzer-worker-01',
  action: 'analyze',

interface PubSubClient {
  publish(event: AgentEvent): Promise;

Example Implementation

import { randomUUID } from 'crypto';
class MessageQueuePubSub implements PubSubClient {
  private subscriptions = new Map();
  private handlers = new Map void>>();
  private messageQueue: AgentEvent[] = [];
  
  async publish(event: AgentEvent): Promise {
    this.messageQueue.push(event);
    
    const handlers = this.handlers.get(event.eventType);
    if (handlers) {
      handlers.forEach(handler => handler(event));
    }
    
    const wildcardHandlers = this.handlers.get('');
    if (wildcardHandlers) {
      wildcardHandlers.forEach(handler => handler(event));
    }
  }
  
  async subscribe(subscription: EventSubscription): Promise {
    const subscriptionId = randomUUID();
    this.subscriptions.set(subscriptionId, subscription);
    
    subscription.eventTypes.forEach(eventType => {
      if (!this.handlers.has(eventType)) {
        this.handlers.set(eventType, new Set());
      }
    });
    
    return subscriptionId;
  }
  
  async unsubscribe(subscriptionId: string): Promise {
    this.subscriptions.delete(subscriptionId);
  }
  
  onEvent(eventType: string, handler: (event: AgentEvent) => void): void {
    if (!this.handlers.has(eventType)) {
      this.handlers.set(eventType, new Set());
    }
    this.handlers.get(eventType)!.add(handler);
  }
}

  timestamp: new Date().toISOString()
});
// Usage: Event subscription

  agentId: 'notification-agent',

Pattern 3: Shared State

Use Case: Agents reading/writing persistent state accessible to multiple participants.

JSON Schema

  "title": "StateOperation",

  "properties": {
    "operation": { "type": "string", "enum": ["read", "write", "delete", "compareAndSet"] },
    "key": { "type": "string", "description": "State key path" },

  "required": ["key", "value", "version", "updatedBy"],
  "properties": {
    "key": { "type": "string" },
    "value": { "type": "any" },

TypeScript Interface

interface StateOperation {
  operation: 'read' | 'write' | 'delete' | 'compareAndSet';
  key: string;
  value?: T;
  expectedVersion?: number;
  agentId: string;
  timestamp: string;
}
interface StateRecord {
  key: string;
  value: T;
  version: number;
  updatedBy: string;
  updatedAt: string;
}
interface StateClient {
  read(key: string): Promise | null>;
  write(key: string, value: T, agentId: string): Promise>;
  delete(key: string, agentId: string): Promise;
  compareAndSet(key: string, expected: T, desired: T, agentId: string): Promise;
  watch(key: string, callback: (record: StateRecord) => void): () => void;
}

Example Implementation

import { randomUUID } from 'crypto';
class SharedStateClient implements StateClient {
  private store = new Map();
  private watchers = new Map void>>();
  
  async read(key: string): Promise | null> {
    return this.store.get(key) || null;
  }
  
  async write(key: string, value: T, agentId: string): Promise> {
    const existing = this.store.get(key);
    const record: StateRecord = {
      key,
      value,
      version: (existing?.version || 0) + 1,
      updatedBy: agentId,
      updatedAt: new Date().toISOString()
    };
    
    this.store.set(key, record);
    this.notifyWatchers(key, record);
    
    return record;
  }
  
  async delete(key: string, agentId: string): Promise {
    this.store.delete(key);
  }
  
  async compareAndSet(
    key: string,
    expected: T,
    desired: T,
    agentId: string
  ): Promise {
    const existing = this.store.get(key);
    
    if (!existing || JSON.stringify(existing.value) !== JSON.stringify(expected)) {
      return false;
    }
    
    const record: StateRecord = {
      key,
      value: desired,
      version: existing.version + 1,
      updatedBy: agentId,
      updatedAt: new Date().toISOString()
    };
    
    this.store.set(key, record);
    this.notifyWatchers(key, record);
    
    return true;
  }
  
  watch(key: string, callback: (record: StateRecord) => void): () => void {
    if (!this.watchers.has(key)) {
      this.watchers.set(key, new Set());
    }
    this.watchers.get(key)!.add(callback);
    
    return () => {
      this.watchers.get(key)?.delete(callback);
    };
  }
  
  private notifyWatchers(key: string, record: StateRecord): void {
    const watchers = this.watchers.get(key);
    if (watchers) {
      watchers.forEach(cb => cb(record));
    }
  }
}
// Usage: Distributed task queue with shared state
const state = new SharedStateClient();
async function claimTask(agentId: string, taskId: string): Promise {
  const key = task:${taskId};
  const task = await state.read<{ status: string; assignee: string | null }>(key);
  
  if (!task || task.value.status !== 'pending') {
    return false;
  }
  
  return state.compareAndSet(
    key,
    { status: 'pending', assignee: null },
    { status: 'claimed', assignee: agentId },
    agentId
  );
}

Example Implementation

import { randomUUID } from 'crypto';
type TaskHandler = (task: DelegationTask) => Promise;
class DelegationOrchestrator implements DelegationClient {
  private taskQueue: DelegationTask[] = [];
  private workers = new Map();
  private handlers: TaskHandler[] = [];
  
  constructor(workers: string[]) {
    workers.forEach(id => {
      this.workers.set(id, { load: 0, capacity: 10 });
    });
  }
  
  async delegate(
    task: Omit, 'id' | 'status' | 'timestamp'>
  ): Promise> {
    const delegateId = this.selectWorker(task.delegateId);
    const fullTask: DelegationTask = {
      ...task,
      id: randomUUID(),
      delegateId,
      status: 'assigned',
      timestamp: new Date().toISOString()
    };
    
    this.workers.get(delegateId)!.load++;
    
    const startTime = Date.now();
    
    try {
      for (const handler of this.handlers) {
        const result = await handler(fullTask);
        if (result.status !== 'failed' || fullTask.task.maxRetries === 0) {
          this.workers.get(delegateId)!.load--;
          return result;
        }
      }
      
      return {
        taskId: fullTask.id,
        status: 'failed',
        error: 'No handler accepted task',
        duration: Date.now() - startTime,
        timestamp: new Date().toISOString()
      };
    } catch (error) {
      this.workers.get(delegateId)!.load--;
      throw error;
    }
  }
  
  onTaskReceived(handler: TaskHandler): void {
    this.handlers.push(handler);
  }
  
  async getWorkerStatus(workerId: string): Promise<{ load: number; capacity: number }> {
    return this.workers.get(workerId) || { load: 0, capacity: 0 };
  }
  
  private selectWorker(preferred?: string): string {
    if (preferred && this.workers.get(preferred)) {
      return preferred;
    }
    
    let best = '';
    let minLoad = Infinity;
    
    for (const [id, status] of this.workers) {
      if (status.load < status.capacity && status.load < minLoad) {
        minLoad = status.load;
        best = id;
      }
    }
    
    return best;
  }
}
// Usage: CEO delegates to workers
const orchestrator = new DelegationOrchestrator(['worker-01', 'worker-02', 'worker-03']);
orchestrator.onTaskReceived(async (task) => {
  const startTime = Date.now();
  
  try {
    const result = await processTask(task.task.input);
    return {
      taskId: task.id,
      status: 'completed',
      output: result,
      duration: Date.now() - startTime,
      timestamp: new Date().toISOString()
    };
  } catch (error) {
    return {
      taskId: task.id,
      status: 'failed',
      error: error instanceof Error ? error.message : 'Unknown error',
      duration: Date.now() - startTime,
      timestamp: new Date().toISOString()
    };
  }
});
// CEO delegates a task
const result = await orchestrator.delegate({
  delegatorId: 'ceo-agent',
  delegateId: 'worker-01',
  task: {
    type: 'data.processing',
    input: { datasetId: 'ds-123', operation: 'aggregate' },
    deadline: new Date(Date.now() + 60000).toISOString()
  },
  priority: 'high'
});

interface ConsensusProposal {
  id: string;
  proposerId: string;
  type: 'vote' | 'raft-like' | 'majority';
  value: T;
  quorum: number;
  votes: Array<{
    voterId: string;
    accept: boolean;
    reason?: string;
  }>;

  timestamp: string;
}
interface ConsensusClient {
  propose(proposal: Omit, 'id' | 'votes' | 'status' | 'timestamp'>): Promise>;
  vote(proposalId: string, voterId: string, accept: boolean, reason?: string): Promise;
  onProposalReceived(handler: (proposal: ConsensusProposal) => Promise): void;

Example Implementation

import { randomUUID } from 'crypto';
class QuorumConsensusClient implements ConsensusClient {
  private proposals = new Map();
  private handlers: ((proposal: ConsensusProposal) => Promise)[] = [];
  private agentId: string;
  
  constructor(agentId: string) {
    this.agentId = agentId;
  }
  
  async propose(proposal: Omit, 'id' | 'votes' | 'status' | 'timestamp'>): Promise> {
    const fullProposal: ConsensusProposal = {
      ...proposal,
      id: randomUUID(),
      votes: [],
      status: 'pending',
      timestamp: new Date().toISOString()
    };
    
    this.proposals.set(fullProposal.id, fullProposal);
    
    for (const handler of this.handlers) {
      await handler(fullProposal);
    }
    
    return fullProposal;
  }
  
  async vote(proposalId: string, voterId: string, accept: boolean, reason?: string): Promise {
    const proposal = this.proposals.get(proposalId);
    if (!proposal) {
      throw new Error(Proposal ${proposalId} not found);
    }
    
    if (proposal.status !== 'pending') {
      throw new Error(Proposal ${proposalId} is already ${proposal.status});
    }
    
    const existingVote = proposal.votes.find(v => v.voterId === voterId);
    if (existingVote) {
      existingVote.accept = accept;
      existingVote.reason = reason;
    } else {
      proposal.votes.push({ voterId, accept, reason });
    }
    
    const acceptCount = proposal.votes.filter(v => v.accept).length;
    
    if (acceptCount >= proposal.quorum) {
      proposal.status = 'accepted';
    } else if (proposal.votes.length - acceptCount >= proposal.quorum) {
      proposal.status = 'rejected';
    }
    
    return proposal;
  }
  
  async getProposal(proposalId: string): Promise {
    return this.proposals.get(proposalId) || null;
  }
  
  onProposalReceived(handler: (proposal: ConsensusProposal) => Promise): void {
    this.handlers.push(handler);
  }
}
// Usage: Agent cluster reaches consensus on task assignment
const agent1 = new QuorumConsensusClient('agent-01');
const agent2 = new QuorumConsensusClient('agent-02');
const agent3 = new QuorumConsensusClient('agent-03');
const allAgents = [agent1, agent2, agent3];
for (const agent of allAgents) {
  agent.onProposalReceived(async (proposal) => {
    const decision = await makeDecision(proposal.value);
    await agent.vote(proposal.id, agent.agentId, decision.accept, decision.reason);
  });
}
async function makeDecision(value: { taskId: string; assignee: string }) {
  const workload = await getAgentWorkload(value.assignee);
  if (workload > 10) {
    return { accept: false, reason: 'Agent workload too high' };
  }
  return { accept: true, reason: 'Agent available' };
}
async function getAgentWorkload(agentId: string): Promise {
  return Math.floor(Math.random()  15);
}
const proposal = await agent1.propose({
  proposerId: 'agent-01',
  type: 'majority',
  value: { taskId: 'task-456', assignee: 'worker-02' },
  quorum: 2
});
console.log('Proposal status:', proposal.status);

Decision Matrix

| Factor | Request/Response | Event-Driven | Shared State | Delegation | Consensus | |--------|-----------------|---------------|--------------|------------|-----------| | Latency Tolerance | Low (synchronous) | High (async) | Medium | Medium-High | Medium | | Coupling | Tight | Loose | Medium | Tight (hierarchical) | Loose (peer) | | Failure Handling | Timeout/retry | Retry listener | Optimistic locking | Task reassignment | Vote retry | | Scalability | Moderate | High | High | High | Low-Medium | | Use Case | RPC calls | Notifications | Cached data | Task distribution | Agreements | | Order Guarantee | Yes | No | Optional | Yes | Yes | | Complexity | Low | Medium | Medium | Low | High |

| Scenario | Recommended Pattern | |----------|---------------------| | Immediate response needed | Request/Response | | Fire-and-forget notifications | Event-Driven | | Shared source of truth | Shared State | | Boss-worker hierarchy | Delegation | | Multi-party decisions | Consensus |

Actionable Takeaways

  • Request/Response: Use when caller needs result before proceeding - direct RPC calls with timeout handling.

  • Event-Driven: Use when one-to-many notification without waiting - pub/sub for loose coupling.

  • Shared State: Use when agents need shared "source of truth" - database or distributed cache with optimistic locking.

  • Delegation: Use when one agent coordinates multiple workers - hierarchical task distribution like OpenClaw.

  • Consensus: Use when multiple agents must agree on outcome - voting or quorum-based decisions.

    • These five patterns form the foundation of inter-agent communication in AgentWire. Choose based on your system's latency requirements, coupling preferences, and failure tolerance. For production systems, consider combining patterns (e.g., delegation + shared state) to meet complex orchestration needs.
